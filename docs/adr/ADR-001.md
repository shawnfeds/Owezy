# ADR-001: Database Strategy — Microsoft SQL Server & Entity Framework Core

## Status
Accepted

## Context
Owezy requires a relational persistence mechanism for bills, items, participants, item claims, authentication state, and audit data. The system requires strong transactional guarantees, relational integrity, clean ORM mapping, and reliable migrations.

## Decision
1. **Database Engine**: Microsoft SQL Server will be the authoritative database engine for production and integration testing.
2. **ORM**: Entity Framework Core (EF Core) will be used for relational mapping and database migrations.
3. **Rejection of Alternatives**: PostgreSQL, MySQL, SQLite (in production), and NoSQL databases are explicitly rejected to maintain architectural consistency and meet strict product constraints.
4. **No Redis**: Caching and temporary state (such as OCR image hashes and OTP tracking) will be handled via SQL Server / in-memory simple stores rather than introducing a separate Redis cache infrastructure.

## Consequences
- **Positive**: Simplified operation, single database technology, strong transactional integrity, seamless EF Core LINQ integration.
- **Negative**: Requires SQL Server licensing or SQL Server Developer/Express containers for local development.
- **Mitigation**: Use SQL Server Express / Docker container (`mcr.microsoft.com/mssql/server`) for local development and testing.
